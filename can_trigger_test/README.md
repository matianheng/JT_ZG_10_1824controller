# AI 触发 CAN 发送测试（12V → 持续发报文）

## 行为

- 固件全量扫描模拟输入（多路复用 8 槽 × 12 路 ADC 通道，含 PA4/PA5）；
- 信号达到 12V（阈值 = ADC 半量程 2048，按“连接器 24V→满量程”假定，
  常量 `THRESH_RAW`，待标定）后，**每 50ms 持续发送 CAN 帧 0x7A1**，回落即停；
- 未触发时每 1 秒发心跳帧 0x7A0（`ENABLE_HEARTBEAT` 可关）。

## 接线

- AI：电位器照旧接 J1-1（台架刻度 0–24V）；
- CAN：控制器 J3-1（CANH，113）/ J3-2（CANL，114）→ 监听工具；
- 波特率 **250 kbit/s**，标准帧；
- ⚠️ 监听工具必须开**正常模式**（参与 ACK）。只听/静默模式下无人应答，
  控制器会不停重发并最终停发，看起来像“没报文”。

## 帧 0x7A1 数据（8 字节）

| 字节 | 含义 |
|---|---|
| 0–1 | 最大原始计数（小端，0–4095） |
| 2 | 最大值所在多路复用槽号（0–7） |
| 3 | 通道编码：高 4 位 ADC 号（0=ADC1,1=ADC2,2=ADC3），低 4 位+ 为通道号（十六进制，如 0x1C=ADC2 的 IN12） |
| 4 | 本轮过阈值的读数个数 |
| 5 | 滚动计数（证明在持续发送） |
| 6–7 | 按 24V 满量程换算的电压×100（小端，如 0x04B0=1200→12.00V） |

## 回报给助手的数据

1. 万用表量 J1-1 恰为 12.0V 时，帧里字节 0–1 的原始计数 → 标定准确阈值；
2. 拧旋钮时字节 2/3 是否变化、变成什么 → 顺带定位 J1-1 的通路
   （若槽号恒定而计数随拧动变化，说明是直连通道；若只在某个槽出现，是多路复用通道）。
