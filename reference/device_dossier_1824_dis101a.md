# 设备档案：鼎立 DL-IO1824G 模块 + DIS101A 10.1 寸屏（骏通起重机力矩限制系统）

整理日期：2026-11-11。来源：厂家铭牌照片、厂家针脚/应用表 xlsx、厂家《DL-IO1210/1824/4032
CANBUS 通信协议 V1.3.0》、原厂固件 dl1824.bin 逆向（pin_recovery_v1 / channel_labels_v1）、
屏端 Android 源码 JT_ZG_10 恢复（docs/screen_protocol.md）、第二轮吊载实验数据。
注意：此 DIS101A 是鼎立的 Android 显示屏，与欧洲车项目的“10.1 寸显控一体机”是两台不同设备。

## 一、DL-IO1824G IO 模块（控制器侧）

- 厂商：湖南省鼎立电气科技有限公司；型号 **DL-IO1824G**；工作电压 9–36VDC；
  板上有 run/power 两颗绿灯（铭牌照片，2026-11-10）。
- 定位：骏通起重机的力矩限制器控制器 + IO 模块（18 路逻辑通道命名即 IO1824 之意：
  16 路非复用 X/Y 口 + 复用口），与 DIS101A 屏配套在役。
- 连接器：J1 = TE 23Pin 1-776228-1 黑（配对 770680-1）；J2 = TE 23Pin 1-776200-5 蓝
  （配对 770680-5）；J3 = TE 8Pin 1-776275-1 黑（配对 776286-1）；插针 770520-3。
- 电源：系统电源 J3-3（线 3，24V）/ J3-4（线 0，GND）；负载电源正 J2-8、J2-15（同为线 3），
  DO 负载电流经此供给——台架只接 J3 不接 J2-8/15 时输出级无电。
- 通讯：CAN1 = J3-1（CANH，线 113）/ J3-2（CANL，线 114）；模块另有 CAN2（固件与
  引脚恢复均证实存在，物理口在 J3/其它口的分配未在针脚表标注，待核）。
- 针脚全表（功能/线号/类型）：见 reference/pinout_dl1018246.md（2026-11-11 按厂家
  xlsx 更正：J1-4 起幅阀线号 135、J1-5 落幅阀 64；J1-3 两表不一致待实物核对）。
- 关键脚速查：
  - 大腔（无杆腔）压力 J1-12（线 94）、小腔（有杆腔）压力 J1-13（线 95），类型 DIH/AI；
  - J1-9 = 5V 传感器电源输出；J2-14 = AO 模拟输出 0–10V/200mA；
  - 防过卷：主钩 J2-1（93）、副钩 J2-2（93A）；蜂鸣器 J2-23（80）；
  - 主令 J1-6（81）、强制 J1-7（82）、超载钥匙 J1-8（83）；
  - 备用脚：J1-1（AI/DIH，功能空）、J1-17（DOH/DIH/AI/PWM，功能空）、J1-19/20、J2-3/6/19/20 空。
- 端口模式可配置（SDO 0x2100 输入 / 0x2101 输出）：X 口 0x08=AI 电压、0x09=AI 电流、
  0x0A=AI 电阻、0x0B=DI 开关量（默认）、0x0C/0x0D=PWMI 频率检测（仅 X00~X03）；
  Y 口 0x01=DO 开关量（默认）、0x02=PWM 占空比输出。

## 二、原厂固件 dl1824.bin（应用固件，逆向结论）

- 文件 189,551 字节，MD5 157a54b586d069b2f4b234120bbd0464；未加密裸镜像，
  ARM Cortex-M4F（STM32F4 类，HAL 风格）；链接基址 0x08010000，前 64KB 为
  Bootloader（不在此文件内）；文件中无长度字段、无尾部校验和。
- 初始栈 0x20006538；外设：CAN1（PD0/PD1 AF9）、CAN2（PB12/PB13 AF9）、
  ADC1/2/3、SPI3（PC10-12 AF6，所接器件未明）、GPIO A–E、FLASH 存参。
- 模拟采集架构：外部模拟多路复用（PE12/13/14 三位选槽，编码=槽号比特反序
  [0,4,2,6,1,5,3,7]）→ 少数 ADC 通道时分采样；12 位、16 点均值滤波。
  **P1/P2 共用 ADC2 IN12/PC2：P1=槽 0、P2=槽 6**（逻辑通道 14/15，映射表 B）。
  PA4/PA5 配了模拟模式但不在常规采样序列（备用模拟脚嫌疑）。
- **臂长/臂角不是本机 ADC 量**：由 CAN1 接收帧提供原始计数（报文记录 11：
  L1/角度1/角度2；记录 12：L2），本机只做两点线性校准；对应帧 ID 未恢复，
  待台架抓 CAN1 报文实证。
- 数字输入多为模拟采样判阈（逻辑通道 A 组 18 路，阈值 ≥851 判真 / <500 判假另一组）；
  纯数字输入仅 PE8–PE11 四脚。输出 50 个 GPIO 推挽脚，无硬件 PWM 引出
  （连接器 PWM 为软件翻转）。PA15 有专用置位封装且初始高（疑输出级使能，待证）；
  PA12 有专用翻转封装（疑运行灯/心跳，待证）。
- 传感器有效性：原始值 ≥0xFFF → 状态 2（AD 超上限）；<101 → 状态 1（信号中断）；
  无效块工程值置 0.01 占位。P1 独有百分比微调 k∈[80,121]（屏侧“重量微调 K”）。
- 厂家算法精度实测（JTC10H6B-1JC，245 点）：显示重量 = 真值×0.997 + 0.456t
  （增益准、恒定偏置 +0.45t，来源未定：空钩零点或钩重未计）；显示幅度系统性
  偏小（平均 −0.70m，约 −0.5m 固定 + −3% 比例）；小腔 AD 近恒定 ~590，大腔随载荷变。
- 刷写：厂家“控制器专用刷程序”工具，输入文件须名 dl1824.bin；升级机制无任何
  文档（协议手册无升级章节）；2026-11-11 台架现象：自研固件多版刷后无反应，
  头号假设为工具依赖运行中固件的升级服务、首刷占位版后通道失效，待回刷原厂
  bin 实验分界（进行中）。

## 三、CAN 通信协议（厂家 V1.3.0 + 逆向互证）

- 物理层：标准帧，波特率可配置，默认 **250 kbps**；周期帧默认 100ms。
- 节点：nodeID 默认 **0x08**（可配 0x08~0x0F，0x00 为广播）；本机 SDO 请求
  0x600+nodeID=0x608、应答 0x580+nodeID=0x588。
- NMT/心跳：上位机心跳 0x710+nodeID（屏发，1000ms）；下位机心跳 0x700+nodeID
  （Byte0 状态：0x00 初始化/0x04 停止/0x05 操作/0x7F 预操作；Byte1 通信状态
  0=故障 1=正常；Byte2 hw_id：0x01=IO1210、0x02=IO4032、**0x03=DL-IO1824**）。
  **上电后停预操作状态：心跳与 SDO 开、PDO 关闭不上传；须收到上位机启动命令
  （NMT cmd 0x01）才进操作状态开始上传；连续 8 秒收不到上位机心跳判通信故障。**
- SDO 参数对象（写后多需 0x1010 存参、写 "save"；恢复出厂 0x1011 写 "load"）：
  0x2000 波特率（03=250K 默认）；0x2001 节点号；0x2002 PDO 周期（n×10ms）；
  0x2010 工况（工作臂/倍率/支腿/区域/副臂/配重/钩选）；0x2011 结构参数
  （中心距、底盘高，0.01m）；0x2012 幅度修正 K（主/副臂，−20~100 有符号）；
  0x2013 零点 / 0x2014 满点（子索引 01=L1、02=L2、03=角度1、04=角度2、
  05=P1、06=P2；AD 12 位 + 实值 0.01）；0x2015 传感器调试模式（子 01~04）；
  0x2016 一键调零 / 0x2017 一键调满（子 01~04）；0x2018 P1/P2 修正系数（80~120）；
  0x2019 重量调试砝码值（子 01=空钩、02=砝码1、03=砝码2、04=砝码3 备用；0.01t）；
  0x1012 请求重量调试数据（子 01~04，开关）；0x1013 请求采集一组；0x1014 请求
  计算调重参数；0x2020 调重参数发送开关；0x1015 调重参数恢复/复位；
  0x2021 范围限制（最大/最小角度、最大幅度/高度）；0x2022 车型 ID（见下）；
  0x2023 固件版本号（VER1 推杆版 0/先导版 1 + 主/次/修正）；0x1021 静音；
  0x2025 虚拟墙开关、0x2026 虚拟墙清零、0x2027 虚拟墙参数（切断点/减速阈值，0.1m）；
  0x2028 臂节模式（0=五节臂、1=六节臂）；0x1017 推杆伸/缩命令（子 1 伸/2 缩向，
  ctrl 0=伸、1=缩）；0x2030 通信协议版本号；0x2100/0x2101 端口模式配置。
- 车型 ID（0x2022 Byte4）：0x17=JTC10H5、0x18=JTC10H6、0x20=JTC12H6B-I、
  0x22=JTC12H6B（其余：0x01~0x0E 为 JPC 系列、0x0F=JTC16H6、0x11=JTC12H5、
  0x12=JTC12H6、0x14=JPC100H5B-I、0x15/0x16=JTC16E5(-II)-I、0x1A=JTC12H5A、
  0x1B=JTC12H6A、0x1D=JTC16H6A、0x1F=JTC12H5B、0x24=JTC12H5B-I）；
  Byte5 车辆种类（0x01=汽车吊默认）；Byte6 主机厂（0x01=骏通默认）。
  改车型 ID 须随后恢复出厂才生效（参数回默认）。
- TPDO 周期帧（基址+nodeID，实测 nodeID=8）：0x190 长度（L1 AD+实值、L2 AD+实值；
  1cm）；0x1A0 角度（角度1/2，0.01°，有符号）；0x1B0 压力（P1/P2，**0.01 MPa**，
  有符号）；0x1C0 风速（备用）；0x1D0 水平仪 XY（备用）；0x1E0 重量调试数据
  （L1/DW/A1/KW）；0x1F0 输入输出状态（按功能位，定义见手册第四章 11 节）；
  0x290 吊重（额定、实际-修正后、百分比、实际-修正前；0.01t/0.01%）；
  0x2A0 幅度+高度（1cm）；0x2B0 ECU（转速/机油压力/冷却温/燃油，备用）；
  0x2C0 环境温度（备用）；0x2D0 故障（Byte0：超载/设备故障/过卷/过放/
  五支腿超压/角度上下限/强制解除；Byte1-2：L1/L2/A1/A2/P1/P2/风速传感器
  故障 2 位编码）；0x380~0x3B0 DO 负载电流（备用）；0x3C0~0x3F0 调重参数
  K1~K5（32 位整型 ×10^6 定点）与砝码/极值；0x480~0x4D0 AI 原始量（备用）。
- RPDO（主机→模块）：0x200+nodeID PWM 占空比设定（Y00~Y17，0~100）；
  0x220+nodeID 实时时钟（年 2 字节+月日星期时分秒，500ms）。
- 已废弃：0x180+nodeID 的 DI/DO 端口位反馈（V1.3.0 起废弃，用 0x1F0 功能帧代替）。

## 四、DIS101A 10.1 寸显示屏（上位机侧）

- 湖南鼎立 DIS101A，10.1 寸 Android 屏；34 针 A 口单一连接器：
  A-01 PWR_IN 电源正、A-02 PWR_GND 电源负、A-03/04 USB_HOST D+/D-、
  A-05/06 GND、A-07 AHD_12V1 视频供电 1、A-08 AHD_12V2 视频供电 2、
  A-09 AHD1_IN、A-17 AHD2_IN、A-25 AHD3_IN、A-34 AHD4_IN（4 路 AHD 摄像头）、
  A-10 RS232_TXD、A-18 RS232_RXD、A-11 USB_VBUS、A-12~16 DI01~DI05、
  A-19/20 CAN1_L/H、A-21/22 CAN2_L/H、A-23/24 RS485_A/B、
  A-26~29 SPK_RP/RN/LP/LN 左右声道、A-30~33 LAN_T+/T-/R+/R- 以太网。
- 软件：Android 应用工程 **JT_ZG_10**（GitHub 私有仓 matianheng/JT_ZG_10-2），
  应用名“河南骏通”，包名 com.hndl.ui，versionName 1.1.67 / versionCode 37，
  compileSdk 34 / minSdk 28 / targetSdk 33；平台签名系统级应用（高通 MSM8953 平台库）。
- 屏不直接说 CAN：经 JNI 串口库走 /dev/ttyHSL2（921600）与屏内下位 MCU 通信，
  由 MCU 转发两路 CAN；串口帧 = 0x02 头 + 命令字节 + 2 字符 ASCII 十六进制长度
  + 数据 + 0x03 尾 + 2 字符校验（实为 8 位累加和，接收端不验）；
  CAN 帧在数据区以 26 字符 ASCII 包承载（命令 0x35 下行 / 0x36 上行）。
  恢复全文见 docs/screen_protocol.md。
- 屏的角色：人机界面 + 参数/车型设置终端（改车型、改参数、标定页面均走上节
  SDO）+ 心跳源（0x710+nodeID）+ 时钟源（0x220+nodeID，500ms）。
  屏侧标定页与参数字典与模块固件配套，自研固件按同一对象字典实现即可无缝复用屏。

## 台架结论（2026-11-11 定版）
- **原厂唤醒序列**：CAN 工具循环发 0x718 数据 `01`（1000ms 心跳）+ 向 **0x001** 发一帧 `01 08`（NMT 启动，本协议管理 ID=0x01，非 CANopen 的 0x000）→ 0x708 变为 `05 01 03`（运行态），全部 PDO 以 100ms 上行。
- **⚠️ J1/J2 易混**：同为 23 针（J1 黑 / J2 蓝），台架散线时极易认错——2026-11-11 曾整日把信号接在 J2 侧（如 J2-12 推杆伸到头信号脚），导致原厂与自研固件在真 J1-12 上均读空（P1 原始恒 1）。**教训：不靠照片/数针认脚，先用万用表找电性锚点**。
- **电压寻针法（可靠流程）**：J1 外线全拔、模块仅 J3 上电，逐针测对 J3-4 电压，唯一约 5V 者即 J1-9（传感器电源）；再以它经电阻回灌邻针、看原厂 0x1B8 哪个通道跳变，定 J1-12。
- **J1-12（大腔压力 P1）前端量程**：喂 J1-9 的 5V → 原厂 0x1B8 P1 原始 = **4060**（近满量程 4095），即该路约 0~5V 量程；演示/标定锚点：5V ↔ 4060。
- **freq_demo v3 台架验证通过**：自研固件读 AI（槽0/PC2，即 P1 通路）→ 连续频率律（原始 ≤40 长亮，线性至 20Hz@4000）→ 45 路输出同律，J1-17 灯随电位器实时变频（0V 长亮、电压越高越快），用户确认「完美」。至此自研固件输入/输出双向锚点闭环。
