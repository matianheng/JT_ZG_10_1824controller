# 输出扫描测试（找 J1-17 的驱动脚）

## 干什么用

正式 Demo 还差一个数据：连接器 J1-17 在板内由主芯片哪只 GPIO 脚驱动。
厂家实际用过的输出脚已从 bin 全部恢复（共 50 个）。本固件把其中 45 个
候选脚**逐个置高 1 秒轮着来**，灯亮的那一步就是答案。

排除的 5 脚（第二轮才用）：PA15（初始高、疑板级使能）、PA12（专用翻转）、
PE12/13/14（3 位编码组）。

## 操作

1. Mac 上：`cd scan_test && chmod +x build.sh && ./build.sh`，得 `build/dl1824.bin`；
2. 用你现成的刷写方式把这个 bin 刷进**备用板**（台架那块）；
3. 接线保持 Demo 台架接法（电源 J3-3/4、负载电源 J2-8/J2-15、灯接 J1-17）；
   **连接器上不要接阀类负载**；
4. 上电观察灯：一轮 = 先齐闪 3 次（轮次标记）→ 停 1 秒 → 然后每 1.25 秒
   推进一步。记下**灯亮时是第几步**（从标记后开始数），以及亮度是否足（24V 全亮）。

## 结果处理

- 灯在某步全亮 → 把步号报给助手，当天即可写正式 io_board（输出侧）；
- 灯一轮里从不亮 → 报助手，走第二轮（5 个特殊脚 + SPI3 扩展假设）；
- 灯微亮/闪烁异常 → 也报助手（可能经驱动芯片或编码组选通，别自己改线）。
