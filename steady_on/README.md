# steady_on：极简长亮固件（2026-11-11）

用户要求先把最简单的事做成：**输出长亮**。本固件刻意做到极简——
没有轮扫、没有 CAN 命令、没有 ADC 采样：

- 上电（时钟归一化后）把 45 路候选输出引脚**全部配置为输出并置高**，
  之后主循环什么都不改——灯接在哪一路都长亮；
- PA12 双闪心跳（run 灯）证明自研固件在跑；
- CAN 每 250ms 发 0x7A0 状态帧（字节5=0xA5 为本固件标记、字节6=版本1），
  带 Bus-Off 自恢复与看门狗喂食（均为已验证代码）；
- 打包基线同其它子工程：栈顶 0x20006538 + 填充 189,551 字节，产物
  仍为 build/dl1824.bin（在 **steady_on/** 目录里构建，勿与 demo_blink 混）。

注意：台架上除灯外其它输出口不要挂负载（45 路会一起带电）。
后续变频演示（demo_blink v7）在此长亮验证通过后再叠加。
