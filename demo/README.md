# Demo：台架模拟量输入 → 控制器输出 24V 点灯

## 目的

自研固件的第一个上板里程碑：证明「AI 读入 → 程序判断 → DO 输出」整条链在自研 dl1824.bin 下跑通。
逻辑刻意做得最简，难点只在上板条件（芯片型号/备用板/刷写验证），不在代码。

## 选脚（都选功能空脚，不占用任何真实阀/开关功能）

| 角色 | 连接器针脚 | 类型 | 依据 |
|---|---|---|---|
| 模拟量输入 | **J1-1** | AI/DIH | 针脚表功能空，类型 AI/DIH 已确认 |
| 灯输出 | **J1-17** | DOH/DIH/AI/PWM | 针脚表功能空，高边输出，可直接带 24V 小灯 |

## 接线（台架）

| 线 | 从 | 到 |
|---|---|---|
| 控制器电源+ | 24V 电源正 | J3-3（线号 3） |
| 控制器电源- | 24V 电源负 | J3-4（线号 0，GND） |
| 负载电源正 | 24V 电源正 | J2-8 与 J2-15（线号 3，DO 高边输出的电源侧，两脚都接） |
| 模拟量信号 | 电位器抽头（白线），经分压/限幅后 | J1-1 |
| 电位器两端 | 红线接 24V（经串阻）、黑线接 GND | 与控制器**共地** |
| 灯 | J1-17 | 灯正极；灯负极接 GND |

## 模拟量输入的安全边界（必读）

- 本模块 AI 的确切量程**未知**（针脚表只给类型 AI/DIH；模块内有 0-10V 模拟输出脚，
  模拟域大概率按 0-10V 设计）。在量程确认前，**进 J1-1 的电压不得超过 10V**。
- 台架要 0-24V 全行程体验，用分压把它映射进 0-10V：电位器红线串 **14K** 固定电阻再接 24V
  （5K 电位器满量程时抽头最高 = 24×5/(14+5) ≈ 6.3V，保守；
  若想满量程接近 10V，把串阻改 7.5K → 最高 9.6V，接法与一体机 AI 模拟实验的既定做法一致）。
- 程序里的阈值按**台架侧电压**（0-24V）写，io 层负责按分压比换算，改串阻只改 io 层一个常数。
- 上电前先用万用表量抽头全程电压，确认上限后再插 J1-1。

## 程序行为

- 每 10ms 采样，5 点滑动平均；
- 输入 ≥12.0V 灯亮（J1-17 输出 24V），≤10.0V 灯灭，中间保持（回差防抖）；
- 代码：`demo_main.c`（逻辑）+ `io.h`（板级抽象）。`io_board.c`（真实 ADC/GPIO 实现）
  待芯片型号与板内引脚对应确认后补，逻辑层不改。

## 上板前置条件（未齐前本 Demo 只做设计与代码，不刷板）

1. 控制器主芯片型号确认（丝印照片）；
2. 备用控制器板（不在在役唯一板上试刷）；
3. 原厂 Flash 整片备份完成（回滚底牌）；
4. 自研 bin 经原 bootloader 在备用板上刷入验证一次。
