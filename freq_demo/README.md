# freq_demo：J1-12 电压变频演示（2026-11-11）

以已实证的 steady_on（长亮）为底座叠加变频，全程不依赖 CAN 命令与步号：

- 输入：每 50ms 采一轮（槽 0，PC2）原始值（= J1-12 通路），480 周期采样、
  双转弃首、4 次平均（均为已验证的采样法）；
- 输出：45 路候选输出一起走变频律（灯在其中一路）：**0V 长亮不闪；
  电压越高频率越高；24V -> 20Hz**，线性连续，占空 50%；
- `RAW_AT_24V`=4000 暂定（待标定：实测 24V 时 0x7A0 字节6-7 的原始值后改）；
- 遥测 0x7A0 每 250ms：字节 0-3 ms 计数、字节 4 滚动计数、
  **字节 5 = 当前频率 Hz（0=长亮）、字节 6-7 = 输入原始值**；
  PA12 双闪心跳、Bus-Off 自恢复、看门狗喂食沿用；
- 打包基线同其它子工程（栈顶 0x20006538 + 填充 189,551），
  在 **freq_demo/** 目录构建，产物 build/dl1824.bin。
