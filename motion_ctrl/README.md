- **过卷切断（文件 03 范围，v2.3 缩减）**：主钩或副钩任一过卷 → 切 J1-5。起幅阀 J1-4 不切（安全方向）；J1-18 待真脚定后再接回切断范围；J1-21 缩臂不参与切断（缩臂减小力矩，属安全方向）。

- **强制开关（J1-7）/ 超载钥匙（J1-8）解除**：v1 未接入（无 DI 通道），待 DI 定位后随正式版加入。

## 过卷信号：CAN ID 0x192（臂头控制器 QH6546，40ms 周期）

**⚠️ v1.1 更正：ID 不是 0xC0。** v1 按十进制 192 写成 0xC0，实车总线（upload-2.asc，2026-11-12）证明 QH6546 发的是 **0x192**，40ms 一帧，数据恒为 `02 00 00 00 01 00 02 00`，无过卷位；v1 全程收不到致超时位常置、J1-5/J1-18 被永久切断。已改。

本车 J2-1/J2-2/J1-11 均为空脚，过卷与接近开关**不走模块 DI**，走 CAN：

| 字节 | 位（厂家 1-based 记位） | 含义 |
|---|---|---|
| byte1 | bit8（= 0x80） | 副钩过卷 |
| byte1 | bit7（= 0x40） | 主钩过卷 |
| byte4 | bit8（= 0x80） | 接近开关触发（v1 只记录，不参与切断） |

**位分配待实车核对**：厂家资料以 1-based 记位（bit8 = 最高位 0x80），代码按此实现并在注释中标明；实车合主令验证时若主/副钩切反，调换 `can_poll_rx()` 里两行的掩码即可。ID 192 周期 40 ms（实车总线核实）；其余字节内容：实测数据恒为 `02 00 00 00 01 00 02 00`，byte0=0x02、byte4=0x01、byte6=0x02 的含义未在资料中说明，v1.1 不解析。

## 原厂通讯骨架（v2 新增，依据手册 V1.3.0 + upload-3 基线）

### NMT 状态机

| 主机发 | 本机转入 | 心跳 0x708 |
|---|---|---|
| 上电 | INIT → PREOP | 上电发一次 `[0x00, com, 0x03]` 后转预操作 |
| 0x001 `[01 08]` 启动 | OPER（操作态） | `[0x05, com, 0x03]`，PDO 开始 100ms 上行 |
| 0x001 `[80 08]` 预操作 | PREOP | `[0x7F, com, 0x03]`，SDO 通、PDO 关 |
| 0x001 `[02 08]` 停止 | STOP | 发一次 `[0x04, com, 0x03]` 后停发（仍收 NMT 以恢复） |

- 主机心跳 0x718 `[0x01]` 1000ms；8 秒收不到 → `com`（0x708 byte1）变 0、0x2D8 bit1 置位，**只报警不锁阀**（文件 04 第 6 项：信号中断只文字报警）。实车基线里屏不发 0x718，`com`=0 是常态，屏照常显示。
- 心跳 1000ms 周期各态都发（手册原文）。

### SDO 服务（厂家方言：读命令 0x43，回 0x60；写命令 0x2F/0x2B/0x2A/0x23，回 0x60；异常回 0x80 + 中止码）

仅预操作/操作态响应。对象表（RAM 值，v2 不存 Flash）：

| 索引 | 子索引 | 内容 | 默认值 | 说明 |
|---|---|---|---|---|
| 0x2000 | 0 | 波特率 | 3（250K） | 只存不换（换波特率须重启） |
| 0x2001 | 0 | 节点号 | 8 | 只存不换 |
| 0x2002 | 0 | PDO 周期 | 10（×10ms=100ms） | 写立即生效，钳 1~200 |
| 0x2010 | 1 | 工况 | 0x20（upload-3 实测屏读回值） | 含义待核对 |
| 0x2011 | 1 | 结构参数 | 0 | 只存不应用 |
| 0x2022 | 1 | 车型 | 0x22（byte4=Model_ID；本车 JTC10H6B-1JC 实测为 0x22） | 改车型后须恢复出厂才生效（手册） |
| 0x2028 | 0 | 臂节 | 0（五节臂） | 待定；1=六节臂 |
| 0x1010 | 0 | 存参 | 写 "save" | 只应答，不落盘（v2 无 Flash 存储） |
| 0x1011 | 0 | 恢复 | 写 "load" | 恢复上表默认值，应答 |

未列出的对象（0x2013/0x2014 零满、0x1017 推杆等）回中止码 `0x06020000`。

### PDO 周期帧（仅操作态，默认 100ms；0x2002 可改）

| ID | 内容 | v2 发什么 |
|---|---|---|
| 0x198 | 臂长 L1/L2（0.01m） | 0（record 11/12 未定） |
| 0x1A8 | 角度 A1/A2（0.01°） | 0（来源未定） |
| 0x1B8 | 压力 P1/P2（0.01MPa） | P1/P2 实测换算；bytes4-7 发 0（未识别，基线恒 596/36） |
| 0x1F8 | IO 状态 | 推断位图：byte0 bit0=主令输入、byte4 bit0=主控阀输出、byte4 bit4=模式；常量 byte0 bit7、byte2 bit3、byte4 bit2、byte7=0x05 照基线抄 |
| 0x298 | 吊重：额定/显示/百分比×100/修正前 | 0（无力限模型） |
| 0x2A8 | 幅度/高度（0.01m） | 0（无臂长/角度） |
| 0x2D8 | 故障位图（自研位定义） | bit0=ID 192 超时，bit1=主机心跳超时，bit2=P1 断线，bit3=P2 断线 |

**P1/P2 压力换算（假定，待台架核对）**：采样电阻约 250Ω（5V→4060 锚点），PT400 量程 0~400bar，4mA 活零点 raw=819。0.01MPa 值 = (raw−819)×4000/3276，钳 0~4000；raw<400 判断线。台架喂电位器 0~5V 核对：5V 应读 4000（40.00MPa），1V 应读 0。

**扩展 TPDO 暂不发送**：0x1C8/0x1D8、0x2B8/0x2C8、0x388…0x4D8 的载荷多为未识别/重复内容（0x2B8/0x2C8 byte5 在伸缩窗口取 2~7，疑似伸缩状态），v2 只发上表 7 帧。

## DI 定位程序（v2 保留：用于定位其余开关 J1-7/J1-8/J1-14/J1-15/J2-12/J2-13）

本板开关量靠 ADC 采样读回（只有 PE8–PE11 是纯数字输入）。v2 每秒扫一轮全矩阵，经 0x7A2 发出；同时 0x7A0 每 250 ms 汇报状态。J1-6/J1-10 已定位（slot1/ch9、slot3/ch9），其余开关用同样方法定位。

**做法（发动机熄火、钥匙 ON）：**

1. 看 CAN 日志：0x7A0 字节 5 应为 `0x25`（动作模式）；PA12 双闪。
2. 拨动待定位的开关（闭合↔断开各停 2 秒以上）：看 0x7A2 矩阵里哪一格（槽号，通道号）跟着跳变（低→高，约 0→4000 或 0→某高值），记下 `(slot, ch)`。
3. 把数填入 `src/main.c` 顶部对应的 `DI_*_SLOT/CH`（现为 -1），重新编译。

**0x7A2 格式（diag_mimic 同款）**：每秒 4 帧发一个槽的 12 路原始值，8 秒发完全部 8 个槽。字节 0–5：3 个通道原始值（u16 LE）；字节 6：高半字节=槽号（0–7），低半字节=帧序号（0–3，帧 f 装通道 3f、3f+1、3f+2）；字节 7：滚动计数。
**通道索引（kChans）**：0=PC3（ADC1 IN13）、1=PA6（IN6）、2=PC5（IN15）、3=PB0（IN8）、4=PB1（IN9）、5=PA7（IN7）、6=PA4（IN4）、7=PA5（IN5）、8=PC4（ADC2 IN14）、9=PC2（ADC2 IN12）、10=PC1（ADC3 IN11）、11=PC0（ADC3 IN10）。

**若拨动开关后没有任何一格跳变**：两个开关可能落在纯数字输入 PE8–PE11 上（ADC 扫不到），下一步需一个 GPIO IDR 扫描固件（读 GPIOE IDR 的 PE8–PE11 位），不要继续猜 ADC 通道。

## 诊断帧

### 0x7A0 状态帧（每 250 ms）

| 字节 | 内容 |
|---|---|
| 0–3 | ms 计数（LE） |
| 4 | 滚动计数 |
| 5 | 模式标志（见下表） |
| 6–7 | 本轮全矩阵最大值（LE，diag_mimic 同款） |

**字节 5 编码**：

| 位 | 含义 |
|---|---|
| bit7 | 模式位：1 = DI-HUNT 模式（基值 0xA5），0 = 动作模式（基值 0x25） |
| bit6 | ID 192 超时故障（>500 ms 未收到） |
| bit5 | 基值签名位，恒 1（随 0x25/0xA5 基值） |
| bit4 | 过卷有效（主钩或副钩任一） |
| bit3 | 伸缩模式（1=伸缩/J1-10 高，0=变幅；HUNT 模式下恒 0） |
| bit2 | 基值签名位，恒 1 |
| bit1 | 主令 ON（J1-6 闭合；HUNT 模式下恒 0） |
| bit0 | 基值签名位，恒 1 |
| bit1–0 | 保留 0 |

HUNT 模式基值 `0xA5`、动作模式基值 `0x25`（bit7 为模式位：1=HUNT、0=动作；bit5/bit2/bit0 为基值签名位，恒 1），典型值：HUNT 正常 `0xA5`、HUNT 且 ID 192 超时 `0xE5`、HUNT 且过卷 `0xB5`；动作模式主令 ON、变幅 `0x27`；动作模式 + ID 192 超时：主令 ON、变幅 `0x67`，主令 ON、伸缩 `0x6F`（2026-11-12 实车 upload-2.asc 实测值，超时位全程置位）。

### 0x7A2 矩阵组帧（每秒 4 帧）

见"DI-HUNT 定位程序"一节。

## 实车验证（发动机熄火、钥匙 ON）

**DI-HUNT 模式（仅当 `src/main.c` 顶部的 DI 常量为 -1 时进入）**：刷入后已确认阀脚应全为 0V（万用表对地量 J1-2/J1-4/J1-5）；PA12 双闪；0x7A0 字节 5 为 0xA5；按"DI 定位程序"拨动开关并记录跳变格。v2 的两个 DI 已填入，不会进入 HUNT 模式。

**动作模式（v2.3，文件 03 字面，伸臂阀除外）**：

1. 主令 J1-6 闭合 → J1-2（主控阀）跳 24V，可听到阀"咔哒"吸合；断开 → 回 0V。
2. 变幅模式（J1-10 低）→ J1-4、J1-5 跳 24V，J1-18、J1-21 为 0V，J1-22、J1-23 为 24V（主卷扬默认得电，v2.5 起；**v2 不再以主令为门控**：主令断开时 J1-4/J1-5 仍为 24V，台架对照原厂验证）。
3. 拨到伸缩模式（J1-10 高）→ J1-4、J1-5 回 0V；**J1-21 跳 24V（v2.3 已接回 PD13），J1-18 仍为 0V（伸臂真脚未定、不驱动）**。
4. 过卷验证：需 QH6546 在线；模拟过卷（或断开 ID 192 超过 500 ms）→ J1-5 应切断回 0V，J1-4 不受影响。

## 台架验证（v2，明天办公室）

台架：模块 + CAN 工具 + 24V + 万用表（发动机熄火，钥匙 ON 思路同实车；台架无 QH6546 时 ID 192 超时属预期，J1-5 被切是保护不是故障）。

**A. 唤醒与 NMT（对照原厂）**：
1. 上电：CAN 上应先出现一次 0x708 `[0x00, 0x00, 0x03]`，随后每 1000ms 发 `[0x7F, 0x00, 0x03]`（预操作，`com`=0，因未收主机心跳）；此时应**没有** PDO（0x198/0x1A8/0x1B8 等全无），SDO 0x2010 读应答正常。
2. CAN 工具循环发 0x718 `[0x01]`（1000ms）+ 向 0x001 发一帧 `01 08`：0x708 应变 `[0x05, 0x01, 0x03]`，7 个 PDO 开始 100ms 上行；停发 0x718 满 8 秒后 0x708 byte1 回 0、0x2D8 bit1 置位，阀不动作变化（只报警不锁阀）。
3. 向 0x001 发 `80 08`：回预操作，PDO 停；再发 `01 08`：回操作态，PDO 恢复。

**B. SDO**：读 0x2010 子 01 → 0x588 应为 `[0x60, 0x10, 0x20, 0x01, 0x20, 0, 0, 0]`；写 0x2002 值为 20 → PDO 周期变 200ms；读不存在对象（如 0x2013）→ 0x588 `[0x80, …, 0x00, 0x00, 0x02, 0x06]`（中止码 0x06020000 小端）。

**C. 阀逻辑（文件 03 字面，重点；v2.3 已改，旧检查卡作废）**：
1. 主令断开 + 变幅模式：J1-4/J1-5 应为 24V（v2 新行为，对照原厂）；J1-2 为 0V。
2. 主令闭合 + 变幅模式：J1-2/J1-4/J1-5 为 24V；切伸缩：J1-4/J1-5 回 0V，**J1-21 应为 24V（v2.3 已接回），J1-18 仍为 0V（伸臂真脚未定、不驱动——J1-18 量到 24V 反而说明刷的还是旧版）**。
3. 喂 QH6546 帧（0x192，40ms，数据 `02 00 00 00 01 00 02 00`）：0x7A0 字节 5 超时位（bit6）应灭；停喂 500ms 后超时位置位，J1-5 切回 0V。

**D. 压力换算（假定核对）**：电位器喂 J1-12（P1）0~5V：1V→0x1B8 P1≈0，5V→P1≈4000（40.00MPa）；喂 0V 时 0x2D8 bit2（P1 断线）置位。J1-13（P2）同理（bit3）。

**E. 待测脚（diag_mimic 轮扫 + 万用表，明天台架补）**：卷扬 J2-4/J2-5（J1-22/J1-23 已确认 PB11/PB10，不用再测），配重 J1-16、J2-7/J2-16，推杆 J2-17/J2-18，油冷 J2-21，空调 J2-22，蜂鸣器 J2-23——逐脚看轮扫到第几步时该针对地 24V，报步号。另拨 J1-7/J1-8/J1-14/J1-15/J2-12/J2-13 看 0x7A2 哪格跳变，定位 DI 格子。伸臂阀 J1-18 真脚不走台架轮扫，等实车 tele_hunt（见 `tele_hunt/README.md`；J1-21 已确认 PD13，不用再测）。

**安全**：验证全程发动机熄火（液压泵不转，阀只吸合不动作）；吊臂下严禁站人；发现异响/异味/异常发热立即断电。首次上车只验证得电/失电（万用表 + 听阀响），不带载动作。
