# dl1824.bin 提取成果（reference/dl1824）

## 先说清边界（重要）

原厂 C 源码**无法**从 bin 还原：变量名、注释、工程结构在编译时已经丢弃，任何工具都变不回来。
本目录是能合法拿到的上限：**机器码级反汇编 + 全部结构化数据资产**。写自研固件时，数据可以直接用，
逻辑按我们自己的实现写（协议已另行从安卓源码恢复），不依赖反编译伪代码。

## 内容清单

| 文件 | 内容 | 怎么用 |
|---|---|---|
| `dl1824_tables.h` | 37 个参数块（共 198 行×7 列）+ 表区原始转储 9956 个 uint16 + 63 个双精度常数 | 直接 `#include` 进固件工程做对照/标定底数；语义（单位/行列含义）待与机型性能表逐块对照后命名，**对照前不要改值** |
| `dl1824_disasm.txt` | 全量反汇编：47,202 条 Thumb 指令（文件偏移 0~0x20000 代码区） | 查某个地址/函数的具体逻辑、找外设寄存器访问点 |
| `functions.md` | 函数图：约 360 个疑似函数入口（地址+估算大小） | 在反汇编里定位函数的索引 |
| `vectors.txt` | 向量表全解：98 个条目（16 内核 + 82 外部中断） | 82 个外部中断与 STM32F407/417 的中断数恰好吻合（旁证，非定论）；中断入口即对应外设的 ISR 地址 |

## 已知结构（体检结论汇总）

- 裸 ARM Cortex-M4F 固件，链接基址 0x08010000（前 64KB 为 bootloader，不在本文件内）
- 代码区约前 128KB；0x20000 后为数据区；表区在 0x220A0~0x26E69
- 双精度浮点运算密集（力矩计算特征）；外设涉及 CAN1/CAN2、ADC1、USART1~3、GPIO A~H、多个定时器、FLASH 存参
- 参数块形态（每块 4~9 行、行内单调递减）推测为分车型/工况的标定或性能曲线组，块间夹有其他参数

## 后续可继续深挖（按需）

1. 对核心函数（如力矩计算）做 Ghidra 伪 C 反编译精读——按函数逐个来，不做全量（全量伪代码质量差、无实用价值）；
2. 参数块与 JTC10H5/H6 性能表逐块对账，定单位与行列语义后在本头文件里正式命名；
3. 芯片型号确认后，用向量表+函数图追 GPIO 初始化代码，恢复引脚级映射。
