# tele_hunt —— 伸缩阀真脚 hunting（不用万用表，靠看臂动）

## 为什么需要它

2026-11-12 实车：motion_ctrl v2 伸缩模式下手柄左推走**副钩卷扬**、伸缩不动（2.asc）；
同操作原厂程序伸缩正常（2-2.asc，臂长 12.88→15.86→11.39m），液压没问题。
v2 代码、模式极性、0x192 均已证实无误，变幅/主控阀（PB14/PD3/PC15）实车正常，
只剩伸缩阀脚可疑：**轮扫认定的 PC13（步24）/PB6（步12）很可能不是 J1-18/J1-21**。
本固件不靠万用表，靠看臂伸不伸，找出真正的伸臂阀脚。

## 做法

- 底本 diag_mimic（45 脚轮扫 + 0x7A2 矩阵），改三处：
  1. 每脚停 **8 秒**（原 1 秒），够推手柄、看臂动；
  2. 跳过已确认的 3 个阀脚：步18（PB14 起幅）、步26（PC15 主控）、步28（PD3 落幅），
     只扫其余 42 脚；
  3. 主控阀 J1-2（PC15）由主令开关 J1-6（slot1/ch9）直接驱动，不参与轮扫，
     保证液压有电；无“齐闪”标记（避免误动阀），一轮扫完直接回绕继续。
- 状态帧改发 **0x7A3**（与 diag_mimic 的 0x7A0 区分），250ms 一帧：
  byte0-3=ms 时间戳，byte4=滚动计数，**byte5=当前候选步号（1..45）**，
  byte6-7=本轮 ADC 最大值。0x7A2 矩阵照常发（可顺带看主令/模式格子）。

## 实车操作（发动机着车，空钩，臂下没人）

1. 刷入 tele_hunt，录 CAN 日志。
2. 主令合上，模式拨到**伸缩**，手柄往**左**推住（伸臂方向）。
3. 看着臂：臂一伸长，记下当时的时间（看手机时钟，精确到秒）。
   一轮 42 脚 × 8 秒 ≈ 5.6 分钟；臂伸了就是当前那脚，别松手柄，等它停稳再记。
4. 把日志 + 伸臂时刻发回来，我从 0x7A3 读出当时步号，那脚就是 **J1-18 伸臂阀**。
5. 缩臂脚 J1-21 同理再跑一轮，手柄往**右**推（缩臂方向），臂一缩短记时间。
   （也可以同一轮里先左推找伸臂、再右推找缩臂，但两步别混，记清各是哪个时刻。）

注意：轮到卷扬阀脚时推手柄会动卷扬（钩升/降），轮到配重/推杆/油冷等脚时
推手柄没反应——都正常，只认“臂伸长/缩短”这一个信号。主令一松主控阀即断，
全停，安全。

## 构建

与 diag_mimic 相同：`./build.sh`，产物 `build/dl1824.bin`（189,551 字节，
头字节 `38 65 00 20 …`）。宿主 `cc -std=c11 -Wall -Wextra -Werror
-Wno-int-to-pointer-cast -fsyntax-only src/main_mimic.c` 已通过。
